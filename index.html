AURA leads active development. Two earlier pilot projects proved that Braille can drive real interaction design on the web, and both remain in use today.

Flagship project — active development

AURA

AURA is an accessible AI orchestration interface that connects blind professionals directly to generative AI platforms and enterprise developer environments. It renders every response as stable, structured text: consistent heading levels, predictable reading order, and no layout shifts that break a screen reader's place. Live regions announce updates without interrupting input, and results are grouped so a braille display shows related information on a single line rather than splitting it across cells. AURA sits between a person and their tools — version control, cloud consoles, project trackers — turning verbose interfaces into something a Braille reader can navigate and direct with confidence.

About the Initiative

The Braille-First Initiative explores Braille as a language for building technology, not only for reading it. Every project starts from Braille-literate design decisions and treats non-visual interaction as the primary path, not a retrofit.
