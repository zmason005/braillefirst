About

The mission

The Braille-First Initiative explores Braille as a language for building technology, not only for reading it. Every project starts from Braille-literate design decisions and treats non-visual interaction as the primary path, not a retrofit.

How projects get built

Two pilot projects, Contractable and the Client BRF & Web Editor, proved that Braille logic and 40-cell display formatting could drive real interaction design on the web. AURA, the current flagship project, extends that same approach to AI: structured, predictable output that a screen reader or braille display can navigate with confidence, built for blind professionals working across code and generative AI tools.
